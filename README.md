# unlit3d_asset_files

Snapshot images for the `unlit_wgpu` and `unlit3d` GPU integration tests, and
for the `unlit3d_examples` scenes.

Referenced from the main repository as `tests/snapshots` (a submodule symlinked
into place) and as the example's default `--snapshot-dir`, and compared with the
SSIMULACRA2 perceptual metric.
